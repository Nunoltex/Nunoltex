# Laserforma Cotizador Windows
Fuente de la aplicación Laserforma Cotizador 1.3.0. El paquete portatil para Windows se publica como archivo comprimido en Releases.
Para compilar: Node.js 22+, pnpm install --frozen-lockfile, pnpm build.
La app lee planos DXF 2D; DWG/PDF y la sincronización entre equipos no están incluidos en esta versión.
La distribución de material es orientativa; valida el resultado final en CypCut.
Esto lo desarrollo una inteligencia artificial.
